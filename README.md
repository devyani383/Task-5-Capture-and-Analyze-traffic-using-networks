# Task-5-Capture-and-Analyze-traffic-using-networks
The objective of this task was to capture live network traffic using wireshark and identify basic network protocol
Tool Used
- Wireshark

## Procedure
1. Opened Wireshark.
2. Selected the active network interface.
3. Started packet capture.
4. Generated network traffic by browsing websites and sending network requests.
5. Stopped the capture.
6. Applied protocol filters.
7. Identified common network protocols.
8. Saved the packet capture file.
## Protocols Identified

### 1. DNS (Domain Name System)
- Purpose: Resolves domain names into IP addresses.
- Example: Converting google.com into its corresponding IP address.

### 2. TCP (Transmission Control Protocol)
- Purpose: Provides reliable and connection-oriented communication between devices.
- Features:
  - Error checking
  - Packet ordering
  - Reliable delivery

### 3. TLS (Transport Layer Security)
- Purpose: Encrypts communication between client and server.
- Commonly used for HTTPS websites.
